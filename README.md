Приложение для Windows, которое подбирает голос по записи WAV и сохраняет профиль JSON для Supertonic 3 и Astra. Создание голоса и распознавание речи работают на компьютере; запись не отправляется на сервер.

Можно скачать модели прямо в приложении, распознать текст записи по желанию и продолжить подбор из готового JSON. Сходство зависит от качества исходной записи; результат удобно проверить новой фразой перед импортом в Astra.

## Как использовать

1. [Скачай последний релиз](https://github.com/Voltur792/supertonic-voice-builder/releases/latest), распакуй **весь ZIP** в отдельную папку и запусти `SupertonicVoiceBuilder.exe`. Нужна Windows 10 / 11, 64 бита. Если программа не запускается, установи [.NET Framework 4.8](https://dotnet.microsoft.com/download/dotnet-framework/net48) и [Visual C++ Redistributable x64](https://aka.ms/vs/17/release/vc_redist.x64.exe).
2. Выбери WAV с чистой речью одного человека без музыки.
3. Укажи папку Supertonic 3 или скачай модель на вкладке **«Модели»**. Если модель уже есть в Astra, можно использовать её.
4. Введи точный текст записи или нажми **«Распознать запись»**. Для распознавания выбери или скачай Whisper на вкладке «Модели». Опция **«Распознавать перед созданием»** включает распознавание перед каждым подбором.
5. Если используешь участок записи, укажи его начало и конец. Текст должен соответствовать этому участку.
6. Выбери режим подбора: **«Пробный»**, **«Обычный»** или **«Тщательный»**. Для продолжения работы выбери существующий профиль в поле **«Продолжить подбор из JSON»**.
7. Введи фразу для проверки и нажми **«Создать JSON»**. Выбери, куда сохранить результат, прослушай его и импортируй JSON в пользовательские голоса Astra.
8. Для обновления открой вкладку **«Обновления»**, нажми **«Проверить обновления»**, затем **«Скачать и обновить»**. Можно включить проверку при запуске. Программа перезапустится после установки; модели, голоса и настройки сохранятся.

Для скачивания моделей и обновлений нужен интернет. После загрузки моделей создание голоса и распознавание доступны без интернета.
